Minimalist clothing store with a bold black-and-yellow aesthetic.

 Features
🖤 Minimalist UI — dark theme with black, yellow, and gray accents.
👕 Product Catalog — browse clothing and view product details.
🔎 Search — quickly find products.
❤️ Favorites — save items for later.
🛒 Shopping Cart — manage selected products.
📏 Size Selection — choose available clothing sizes.
📱 Responsive Design — optimized for mobile devices


Design
The interface is built around a simple visual identity:
Primary background: black
Accent color: yellow
Typography: clean and modern
Product presentation: large images and minimal descriptions
